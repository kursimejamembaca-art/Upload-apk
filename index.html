Unggah BISINDO Bicara ke GitHub dan Codemagic

Halaman ini membuat atau memakai ulang repositori privat, mengunggah isi ZIP proyek Android, lalu (jika token Codemagic diisi) menambahkan aplikasinya di Codemagic dan menjalankan build APK. Tidak perlu Git di komputer.

GitHub

Buat di github.com/settings/tokens. Token klasik cukup dengan scope repo. Token hanya dipakai di halaman ini dan langsung dihapus setelah selesai.

Jika repositori dengan nama ini sudah ada, isinya akan diganti dengan isi ZIP.

Pilih bisindo-app.zip versi Android (harus berisi codemagic.yaml).

Codemagic (opsional)

Ambil di Codemagic: User settings → Integrations → Codemagic API. Jika diisi, halaman ini membuat kunci deploy khusus di repositori, menambahkan aplikasi ke Codemagic, lalu memulai build. Token juga dihapus setelah selesai.
